Start from the Mermaid files in `docs/diagrams/` when adapting an explanation. The paired SVGs are standalone renderings for README links and must be updated with their source whenever a boundary changes.

Use the diagrams to distinguish local deterministic work, optional provider calls, account and billing choice, manual review, and publication. Do not depict a provider call or publishing step as automatic unless a requested workflow explicitly authorizes it.
